# Gestores de geometría

## Apilar en bloques `pack`

- `side`   → Lado de colocación
- `fill`   → Expandir en una dirección
- `expand` → Expandir en el espacio sobrante
- `padx`   → Margen externo horizontal
- `pady`   → Margen externo vertical
- `ipadx`  → Margen interno horizontal
- `ipady`  → Margen interno vertical

## Sistema de filas y columnas `grid`

- `row`                → Fila
- `column`             → Columna
- `sticky`             → Lados de anclaje
- `columnspan`         → Ocupar varias celdas
- `rowspan`            → Ocupar varias celdas
- `padx`               → Margen externo horizontal
- `pady`               → Margen externo vertical
- `.columnconfigure()` → Expandir en el espacio sobrante
- `.rowconfigure()`    → Expandir en el espacio sobrante

## Coordenadas absolutas o relativas `place`

- `x`      → Coordenada absoluta X
- `y`      → Coordenada absoluta Y
- `relx`   → Coordenada relativa X
- `rely`   → Coordenada relativa Y
- `anchor` → Lados de anclaje
